# 🌊 제주 답사 코스 메이커

제주특별자치도 역사문화 데이터(공공데이터포털 오픈 API)로 지역·주제·일정만 고르면 가까운 장소를 묶어 최적 동선의 답사 코스를 만들어 주는 사이트입니다.

## 1. 사이트 구조 (화면 구성)

별도 페이지 이동이 없는 **단일 페이지(`index.html`) 1개 + 상세 팝업 1개**로 이루어져 있습니다.
PC에서는 왼쪽 패널과 오른쪽 지도가 나란히 보이고, 모바일에서는 하단 탭으로 목록과 지도를 전환합니다.

| # | 화면 | 무엇을 보여 주는가 |
|---|------|--------------------|
| 1 | 머리글 | 사이트 제목과 한 줄 설명 |
| 2 | 답사 코스 자동 만들기 | 지역·주제·일정(반나절 4곳/하루 7곳/1박 2일 12곳)·출발 기준(자동/내 위치/숙소)을 고르고 `코스 만들기`를 누르는 영역. 숙소를 고르면 검색창과 "지도에서 찍기"가 나오고, "기준 위치로 돌아오는 코스" 옵션이 있음 |
| 3 | 검색·필터 | 키워드 검색(장소명·제목·주제·주소·저작자·내용), 분류·대분류·지역·자료유형 필터, 정렬(번호/장소명/발행일/가까운순), 필터 초기화, 찜만 보기, "전체 N건 중 M건" 건수 표시. 지도 핀도 함께 걸러짐 |
| 4 | 나만의 답사 코스 | 만들어진(또는 찜한) 코스의 방문 순서, 구간별 이동거리·시간, 순서 위/아래 이동, 체류시간·이동수단(자동차/버스/도보) 설정, 동선 최적화, 가까운 곳 추가, 링크 복사·일정 복사·인쇄. 비어 있으면 사용 안내 문구 |
| 5 | 장소 목록 | 조건에 맞는 장소 카드(15개씩, 페이지 이동). 카드에서 찜하기·상세보기·지도에서 보기. 카드의 설명은 문장 단위로 끊은 요약 |
| 6 | 지도 | 장소 핀(OpenStreetMap + Leaflet), 핀 클릭 시 요약 팝업, 코스를 선으로 연결, 내 위치·숙소 마커 |
| 7 | 상세 팝업 | 맨 위에 "한눈에 보기" 요약, 그 아래 주소·주제어·저작자·발행일, 접어 둔 "전체 내용 읽기"·초록·목차·참고문헌·자료 정보(번호·좌표 등), 찜하기·지도에서 보기·OpenStreetMap·제주 디지털콘텐츠 원문 링크 |
| 8 | 하단 탭 (모바일 전용) | 화면 너비 860px 이하에서만 나오는 `📋 목록·코스` / `🗺 지도` 전환 탭 |
| - | 인쇄 화면 | 인쇄 시 "나만의 답사 코스"와 지도만 출력 |

## 2. 데이터 구조

```
브라우저(index.html) ──/api/places──▶ 서버 ──▶ 공공데이터포털 API 2개(일반정보·위치정보)
```

- 브라우저는 API 키를 모릅니다. 서버가 환경변수의 키로 두 API를 호출해 `데이터 고유번호` 기준으로 합친 뒤(120건) 내려줍니다. 결과는 1시간 캐시합니다.
- `places.js` 공통 로직 / `server.js` 로컬 실행 서버 / `api/places.js` Vercel 서버리스 함수

## 3. 실행 방법

환경변수 (로컬은 `.env.local`, Vercel은 Environment Variables에 등록 — `.env.local`은 git에 올리지 않음)

| 이름 | 설명 |
|------|------|
| `JEJU_CULTURE_INFO_KEY` | 일반정보 API 서비스키 |
| `JEJU_CULTURE_LOCATION_KEY` | 위치정보 API 서비스키 |
| `JEJU_CULTURE_INFO_URL` | 일반정보 API 요청 주소 |
| `JEJU_CULTURE_LOCATION_URL` | 위치정보 API 요청 주소 |

```bash
node server.js   # http://localhost:3000
```

## 4. 사용자 관점 개선점 10가지

처음 이 사이트를 쓰는 사람 입장에서 살펴본 제안입니다. 이 중 **2번·6번·8번은 반영했고**(아래 5장), 나머지는 아직 고치지 않았습니다.

1. **로딩 표시가 없습니다.** 데이터를 API로 받아오는 동안 목록과 건수가 비어 있어 멈춘 것처럼 보입니다. 스피너나 "불러오는 중…" 문구가 필요합니다.
2. **모바일에서 지도가 너무 아래에 있습니다.** 모바일에서는 패널이 약 4,000px 길이라 지도가 맨 아래(약 4,250px 지점)에 있어 스크롤해도 한참 뒤에야 나옵니다. `지도 / 목록` 전환 탭이나 지도로 바로 가는 버튼이 필요합니다.
3. **첫 화면에 사용 방법 안내가 없습니다.** 코스 만들기, 찜하기, 숙소 기준 등 기능이 많은데 처음 온 사람에게 순서를 알려 주지 않습니다. 3단계 안내나 예시 버튼("제주시 하루 코스")이 있으면 좋습니다.
4. **오류가 났을 때 일반 사용자가 이해하기 어렵습니다.** "API 401 Unauthorized" 같은 기술 문구가 그대로 보입니다. "잠시 후 다시 시도해 주세요" 같은 쉬운 문구와 다시 시도 버튼이 필요합니다.
5. **필터가 너무 많고 용어가 어렵습니다.** 분류·대분류·자료유형 등 용어의 차이를 알기 어렵습니다. 자주 쓰는 필터(지역·주제)만 먼저 보이고 나머지는 "상세 필터"로 접는 편이 좋습니다.
6. **코스를 만든 뒤 결과 위치가 눈에 띄지 않습니다.** `코스 만들기`를 눌러도 결과가 아래쪽 "나만의 답사 코스"에 생기므로, 자동으로 그 위치로 이동하거나 강조해 주어야 합니다.
7. **이동시간이 부정확합니다.** 직선거리×1.4로 추정한 값이라 실제 길 안내와 차이가 큽니다. 최소한 화면에서 "추정값"임을 눈에 띄게 알리거나, 길찾기 링크(카카오맵·네이버지도 등)를 구간마다 연결하면 좋습니다.
8. **장소 내용이 길고 딱딱합니다.** 카드와 상세에 논문·자료 형식의 긴 텍스트가 그대로 나옵니다. 사진, 한두 줄 요약, "더보기" 처리가 있으면 읽기 쉽습니다. 상세 팝업의 "데이터 번호·자료형태·언어" 같은 항목은 일반 사용자에게는 불필요합니다.
9. **찜한 장소와 코스가 기기에 묶여 있습니다.** 찜은 브라우저에만 저장되어 다른 기기에서 볼 수 없고, 브라우저 데이터를 지우면 사라집니다. 코스 링크 공유 기능은 있으나 찜 목록 내보내기·불러오기가 없습니다.
10. **접근성과 사용 편의 부분이 부족합니다.** 지도 핀과 이모지 중심의 표시, 작은 글씨(안내 문구 11px), 색 대비, 키보드·스크린리더 대응이 약합니다. 또 지도는 외부 CDN에 의존하므로 접속이 불안정하면 지도가 비어 보입니다.

## 5. 개선·추가한 내용

개선점 10가지 중 2번·6번·8번을 반영했습니다. 모두 `index.html`만 수정했습니다.

### 개선 2번 — 모바일에서 지도 찾기 어려움 → 목록/지도 전환 탭
- **문제:** 모바일에서 패널이 약 4,000px 길이라 지도가 맨 아래에 있었습니다.
- **고침:** 모바일(너비 860px 이하)에 하단 고정 탭 `📋 목록·코스` / `🗺 지도`를 추가했습니다. `지도`를 누르면 지도가 전체 화면으로 나오고, `목록·코스`를 누르면 되돌아옵니다.
- **연결:** 카드나 팝업의 `📍 지도에서 보기`를 누르면 자동으로 지도 탭으로 바뀌고 해당 장소 팝업이 열립니다. 코스를 만들면 목록 탭으로 돌아옵니다. 안내 메시지·상세 팝업이 탭에 가려지지 않게 층 순서도 조정했습니다.
- PC 화면은 기존과 같고 탭은 보이지 않습니다.

### 개선 6번 — 코스 만든 뒤 결과가 눈에 안 띔 → 자동 이동 + 강조
- `✨ 코스 만들기`(및 순서 최적화 등 코스 변경)를 누르면 "나만의 답사 코스" 카드가 화면 맨 위로 이동하고, 테두리가 잠깐 깜빡여 어디가 결과인지 알려 줍니다.
- 모바일에서는 안내 문구에 "아래 🗺 지도 탭에서 동선 확인"이 함께 나옵니다.

### 개선 8번 — 장소 내용이 길고 딱딱함 → 요약 + 접기
- **카드:** 설명을 `(중략)` 제거 후 문장 끝에서 끊어 약 160자 요약으로 보여 줍니다(단어 중간에서 잘리지 않음).
- **상세 팝업:** 맨 위 "한눈에 보기" 요약(약 220자) → 핵심 4가지(주소·주제어·저작자·발행일) 순서로 보여 줍니다. 긴 본문과 초록·목차·참고문헌은 접어 두었고(누르면 펼침), 일반 사용자에게 필요 없는 항목(데이터 번호, 우편번호, 좌표, 자료형태, 언어, 범위, 출처, 기여자, 기준일자 등)은 "자료 정보" 한 칸에 모았습니다.

### 확인한 방법
브라우저에서 모바일(375×812)과 PC(1280×800) 크기로 직접 눌러 확인했습니다.
- 모바일: 탭 전환(지도 전체 화면·동선 선·핀 표시), `지도에서 보기` → 지도 탭 전환 + 팝업, 코스 만들기 후 카드 이동·강조, 상세 팝업 요약/접기, 팝업이 탭 위에 표시
- PC: 탭 숨김, 지도·패널 기존 배치 유지, 코스 만들기 정상(7곳)
- 확인하지 못한 것: 부드러운 스크롤 효과(미리보기 창에서는 동작하지 않아 즉시 이동 방식으로 구현), 실제 스마트폰 기기에서의 동작
